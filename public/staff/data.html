Data retention

How long applicants' personal data is kept. Erasing removes details, photos, confirmation numbers and codes; case numbers, stages and the audit trail stay.

Submitted entries

Setting: RETENTION_DAYS_AFTER_SUBMISSION. Selected applicants need their details for the visa forms until the end of the following DV year, so keep this long: about 18 months (548 days).

Unsent website entries and unused invitations

Setting: RETENTION_DAYS_UNSENT. Entries never sent for checking and invitations nobody used, counted from their last change. For example 60 days.

Rules that are switched on run by themselves every 6 hours. Set the numbers on Render (Environment), then redeploy. An admin can also erase a single case from its page when an applicant asks to be deleted.

Backups

Download a full copy of everything: cases, photos, passport pictures, payments, partners, payouts and the audit log.

Personal data stays encrypted inside the file, so the file alone is unreadable: it needs the site's DATA_ENCRYPTION_KEY, which you keep separately (for example in a password manager). Keep backups somewhere safe and private, such as an encrypted drive. Restoring: see "Backups" in the README. Every download is recorded in the audit log.
